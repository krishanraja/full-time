# 14 - Original build plan, historical record

- **Status:** Historical, do not execute
- **Original date:** 2026-06-17
- **Last reviewed for provenance:** 2026-08-11
- **Purpose:** Preserve the assumptions that shaped the first prototype and explain what replaced them.

## Why this record exists

The first plan defined Full Time as a roughly 60-second, single-voice, day-after recap product. It established useful foundations: a dark broadcast identity, structured match data, fail-closed factual checks, a morning habit, PWA delivery, synthetic-media disclosure, and a refusal to imitate real broadcasters.

It is no longer an implementation plan. Current doctrine lives in [`00-product.md`](./00-product.md), current code in [`18-world-class-pundit-system.md`](./18-world-class-pundit-system.md), and current release state in [`19-release-state.md`](./19-release-state.md).

## Original assumptions

The June plan proposed:

- one calm reporter voice;
- one short recap per match;
- restrained observation instead of strong judgments;
- a founder-trained voice corpus;
- structured score, event, and statistic grounding;
- a deterministic accuracy gate and model judge;
- one daily morning drop with push, share pages, and RSS;
- Big Five scope and no required account;
- audience-first monetization;
- no betting, broadcaster imitation, or community layer.

## What survived

- Facts remain closed-world and evidence-linked.
- Factual, entity, numerical, and attribution failures still block publication.
- Synthetic-media disclosure remains mandatory.
- The product remains day-after, audio-first, PWA-friendly, and account-optional.
- The visual system remains lime on a dark broadcast surface.
- Betting, living-pundit imitation, and unlicensed media remain prohibited.
- Publication still fails closed.

## What changed

| Original plan                    | Current system                                      | Reason                                            |
| -------------------------------- | --------------------------------------------------- | ------------------------------------------------- |
| One voice and one sensibility    | Six distinct AI Pundit products                     | Choice must change the mind, not just the timbre  |
| About 60 seconds per match       | One 5 to 8-minute morning show per pundit           | Insight, story, humour, and receipts need room    |
| No staked verdict                | Bold evidence-grounded judgment                     | Differentiation requires a point of view          |
| One recap gate                   | Claim licensing plus hard and qualitative harnesses | Accuracy alone can still produce bland content    |
| A model retries the whole script | Targeted failed-beat repair                         | Full rewrites wash out personality                |
| Single TTS profile               | Six versioned performance systems                   | Delivery is part of the persona                   |
| Retrospective summary            | Pre-kickoff prediction and public receipt           | Accountability makes intelligence testable        |
| Launch by production completion  | Launch by multidimensional evidence                 | Deployed code cannot self-approve taste or rights |
| GitHub schedule primary          | `vercel.ts` primary, GitHub manual recovery         | One production schedule source of truth           |

## Historical value

Use this record when a current decision appears arbitrary. It shows which prototype constraints were deliberate and which were replaced after the product's differentiator became clear.

Do not copy commands, gates, pricing, models, voices, timings, or architecture from this file into current work.
